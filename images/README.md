# Photos — how to add them

Each tour has one folder, and inside it **one folder per stop** — named the same as the stops
on the page. Drop **as many photos as you like** into a stop's folder.

- Any filename is fine. iPhone **HEIC** photos are fine (they get converted automatically).
- Drop several into one stop and they become a swipeable photo gallery for that stop.
- To remove a photo later, just delete it from its folder.

## To publish

After dropping photos in, double-click **publish-photos.command** (one folder up).
Wait about a minute, then **hard-refresh the page (Cmd+Shift+R)** — browsers cache images.

Landscape photos look best. Big files are fine.
